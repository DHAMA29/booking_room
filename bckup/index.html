    Request

    Isi data peminjaman

    Lengkapi informasi berikut untuk mengajukan peminjaman. Data digunakan pengelola untuk meninjau pengajuan Anda.

    Format NIM UGM: tahun / nomor urut / kode program / nomor

    Harus menggunakan email UGM berakhiran @mail.ugm.ac.id

    +62

    Ketik tanpa awalan 0 / 62 — contoh: 812-3456-7890

    0 / 500 karakter

    Ketentuan Peminjaman

    • Peminjaman hanya untuk mahasiswa aktif UGM (data NIM & email UGM diverifikasi).
    • Durasi peminjaman 1–2 jam per pengajuan, maksimal 14 hari sebelum tanggal pemakaian.
    • Peminjam bertanggung jawab atas kerusakan fasilitas dan perangkat selama pemakaian.
